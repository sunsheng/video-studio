# 多视图卡片

## 为什么不能只出一张

一张大头照锁不住服装，一张全身照锁不住脸。

「多角度」不是形容词，是可数的：少一个角度，下游就少一处可比对的参照。
转身图（turnaround）是这一行的标准做法——正面、四分之三、正侧、背面、
面部特写，五个方向把一个人从各个面固定下来。

同样的道理适用于场景（建立、主机位、反打、细节）和道具（正、侧、
使用状态、比例参照）。

## 角色卡的视图

<!-- 词表:character_view -->

前五个（`front_full` / `three_quarter` / `profile` / `back` /
`face_close`）**必需**，缺一个提交就会被挡下。后三个按片子需要加：
有台词或情绪戏就加 `expressions`，有道具交互就加 `hands_props`，
服装本身是识别点就加 `wardrobe_detail`。

## 场景卡的视图

<!-- 词表:scene_view -->

前四个必需。跨时间段（同一个地方要拍日景和夜景）加 `lighting_variants`；
有人物入场、需要合成对位时建议加 `empty_plate`。

场景卡要求**同一空间、同一布景陈设**，变的只有机位和光线。

## 道具卡的视图

<!-- 词表:prop_view -->

四个都必需——道具少一个面，持握关系就对不上。

## 主视图先出，其余以它为参考

每张卡有且仅有**一个**主视图：角色是 `front_full`，场景是
`establishing`，道具是 `front`。

生成顺序是硬要求，不是优化建议：

1. **主视图先出、单独出**，而且必须排在 `views` 的第一位——**顺序就是生成
   顺序**，主视图不先出，后面的视图没有参考图可挂。
2. 其余视图按顺序出，每一张都挂**累积的参考**：`derived_from` 第一项是主视图，
   后面补上这一张之前已经定稿的其余视图。提示词 = 逐字相同的
   `identity_prompt` + 本视图特有的机位/表情描述。
   文字负责说清「要什么角度」，参考图负责保证「是同一个人」。
3. 某个视图与主视图明显不符 → 重生成**那一个视图**，不要接受漂移。

**为什么不能并行出八张**：并行生成八个视图，出来的是八个长得像但不是
同一个人的角色。这与用哪个后端无关，是生成模型的固有性质——
每一次生成都是独立的一次掷骰子，除非有一张图把结果钉住。

**为什么要累积挂，而不是只挂主视图**：出第 5 个视图时把前 4 个都挂上，
模型看见的是同一个人的四个角度，新视图必须同时与它们自洽——漂移无处可去。
只挂主视图的话，模型每次都是「从一个角度推另一个角度」，前面几个视图
积累的信息全用不上。

所以非主视图的 `derived_from` 必填，是一个**列表**：

```jsonc
"views": [
  { "view": "front_full",    "is_anchor": true },
  { "view": "three_quarter", "derived_from": ["front_full"] },
  { "view": "profile",       "derived_from": ["front_full", "three_quarter"] },
  { "view": "back",          "derived_from": ["front_full", "three_quarter", "profile"] }
]
```

只能挂**已经定稿**的视图——指向排在自己后面的，那时它还不存在。上限 10 张。
少挂几个不算错，只是锁得弱一点；一个不挂就是没有锚点，提交会被挡下。

## `identity_prompt`：一次写定，逐字复用

每张卡有一段 `identity_prompt`，**一次写定**，此后所有视图的提示词都以
它逐字开头。不复述、不缩写、不「优化措辞」。

角色卡的这一段要**逐字包含**分镜定下的那段身份锁
（`consistency_lock.character`）。卡片可以写得更细——脸型、肤色、瞳色
这些是出图才需要锁的，视频提示词里用不上——但那段身份锁必须原样在里面。
写成另一段近义改写，卡上的人和成片里的人就不是同一个人了。

```
分镜 character_lock.identity_lock
  → 视觉资产 consistency_lock.character（逐字复制）
      → 角色卡 identity_prompt（逐字包含，可以再补细节）
          → 每个视图的 prompt（逐字开头）
```

## 卡片是量具，不是剧照

**角色卡与道具卡**共享一套拍摄约束：

> 中性灰底，均匀柔光，无阴影投射，
> 画面中不出现乱码文字、假字幕或水印

**「主体完整入画不裁切」不属于共享约束，它只对全身类视图成立。**
`face_close`、`expressions`、`wardrobe_detail`、`detail` 这几个视图**按定义
就是裁切的**——面部特写要求裁到肩以上，服装细节要求裁到那块料子上。把
「不裁切」套上去，等于让模型在「特写」和「全身」之间二选一，而它会选后者：
参考图全是全身，那是最省力的方向。

所以：全身类视图（`front_full` / `three_quarter` / `profile` / `back` /
道具的 `front` / `side`）写「完整入画不裁切」；特写类视图写它**该裁到哪**。

## 参考图要跟目标构图同类，否则它们在打架

**这一条是 2026-09-05 用三个样本换来的，不是推理出来的。**

那次给特写类视图写了完全正确的取景描述——「面部特写，肩部以上入画」
「画面充满白色布料」——出来的**全是全身照**。三张一致：

| 视图 | 挂了几张参考 | 语义指令 | 取景指令 |
|---|---|---|---|
| `face_close` | 4 | ✅ 中性表情照做 | ❌ 仍是全身 |
| `expressions` | 5 | ✅ 三格并排、三种表情全对 | ❌ 每格仍是全身 |
| `wardrobe_detail` | 7 | — | ❌ 仍是全身 |

`expressions` 那张最说明问题：**同一句提示词里语义部分全部生效，唯独取景
部分被无视**。所以不是模型没读提示词，是**参考图在压构图**——而挂上去的
四到七张全是全身照。

同一轮里 `profile` 却成功转到了九十度。差别在于：转身是**姿态**变化，参考图
里可推断；裁切是**取景**变化，参考图里没有，而且每一张都在反向示范。

所以挂参考时按构图分家：

- **全身类视图**：累积挂前面已定稿的全身类视图。它们构图同类，互相强化。
- **特写类视图**：只挂**锚点**（身份的唯一来源）加上前面已定稿的**特写类**
  视图。第一张特写只有锚点可挂，后面的特写就有同类可挂了。

**不要把全身照挂给特写视图**——参考的职责是锁身份，不是替它决定裁到哪。

> 这条规则本身还没有真机验证过（写下它的那一轮只证明了「挂满全身照会失败」，
> 没证明「少挂就会成功」）。验过之前不要把它写成校验去挡人。

戏剧性打光留给成片。这两类卡的用途是**被比对**——底色一花、光一斜，
就没法判断第三个视图和主视图是不是同一个人了。

**场景卡不吃「中性灰底」这一条，套上去是自相矛盾的。** 场景卡要比对的
不是一个可以抠出来的主体，而是**那个空间本身**：建立镜头要给出空间全貌，
反打要证明轴线两侧成立。把它放在灰底上，这些一样都验不了——出来的是一张
悬空的布景图，既不像那个地方，也没法拿去跟成片对。

场景卡的共享约束换成这套：

> 自然光照与真实环境，同一空间、同一布景陈设，
> 变的只有机位与光线时段，画面中不出现乱码文字、假字幕或水印

也就是说：**「同一个东西」这条要求不变，变的是拿什么当背景。**
角色和道具靠中性底把主体孤立出来，场景本身就是主体，孤立不了。

## 画幅：一张卡一套规格

同一张卡的所有视图用**同一个** `aspect`，混用会被挡下。一张竖一张方，
看的人会以为是不同批次生成的。

常见选法：角色卡走竖构图（全身要完整入画），场景卡走横构图或跟成片
同画幅，道具卡走方构图。选哪个都行，一张卡里统一就行。

**卡片的画幅和成片画幅是两回事**，不必相同——卡片是参考素材，不是成片帧。
真正必须等于成片画幅的是每镜的首帧图（i2v 用），那是另一件事。
