# 样例：提示词包

同一部片子的五镜提示词。目标系列是 MiniMax，所以**没有 `negative`**——
那条系列不吃这个参数，写了提交时就会被挡下。

## 为什么这样写

**身份锁逐字复用。** 五镜的 `positive` 里都有同一段：

> 20岁东亚女性，长黑发及胸，白色无袖连衣裙，低帮白色板鞋，奶油色小斜挎包

一字不差。不是「同一位女孩」，不是「前述女孩」——模型没有记忆，
每一镜都是从零开始，写「同一位」它不知道是哪一位。

**约束写成正向的完整句子。** 每一镜结尾都有：

> 一镜到底，不切场景，人物保持在画面中央，画面中不出现任何文字、标志或水印。

这几句替代了负向提示词。第三镜例外——那一镜镜头要摇走，
所以去掉了「人物保持在画面中央」。**约束要跟着镜头调整，不是复制粘贴的咒语。**

**分镜的物理事实被翻译进了提示词。**
第二镜的「湖风从左侧推来，裙摆和发梢一起向右扬；落地时脚踝先内扣再蹬直」
就是分镜 `three_facts` 的前两条。分镜里想清楚的东西，
在这里变成模型能读的句子——不要在这一步重新编。

**运镜是一句话，不是形容。**
「镜头缓慢前推」「镜头横向跟移，与她同速」「镜头向右缓慢横摇」
「固定机位，镜头不移动」「镜头缓慢升高」。每镜一个，对应分镜的
`camera_motion` 枚举。

**`audio` 每镜都写了三层。** 环境声、拟音、有没有对白和音乐，
说清楚。这个系列是音视频联合生成的。

**种子固定。** 101001 到 101005，连号。不固定就没法复现，
出了问题也无从对比。

**尺寸一致。** 五镜都是 1080×1920，帧率都是 30。
帧数按各镜时长算：1.4 秒 × 30 = 42 帧，2.4 秒 × 30 = 72 帧。
加起来正好是剧本的十秒。

## `references` 怎么组

五镜都写了 `references`，每镜按「身份 + 空间（+ 物件）」配：

- 每一镜都挂 `C01`——角色卡，全片同一张，不换视角。
- 各挂各自的场景卡（`SC01` / `SC02` / `SC03`）。
- 有可辨认道具的两镜额外挂 `P01`。

三到四张就够。挂满不是目标：参考之间会互相稀释，九张互不相干的图
每一张的约束力都变弱。

参考解决「像不像同一个人」，上面那段逐字复用的身份锁解决「模型有没有被
告知要像谁」。**两条都要，少一条角色就会在第三镜变成另一个人。**

## sh02 那个 `guides` 是干什么的

```jsonc
"guides": [{ "kind": "image", "at_frame": 0, "asset_id": "sh01.tail" }]
```

sh01 结束在她转头微笑，sh02 是她跑起来——**同一个动作跨了两镜**。
对模型来说每一镜都是第一镜，在提示词里写「接上一镜」它读不到任何东西；
把 sh01 的尾帧锚在 sh02 的第 0 帧，生成的才是两条流的续接。

其余四镜没有挂：它们之间换了场景或换了时间，硬接会让模型试图从上一镜的
画面演化出一个不相干的场景，出来的是渐变糊团。**接续是连续动作的手段，
不是转场的替代品。**
