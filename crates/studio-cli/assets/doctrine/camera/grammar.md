# 镜头语法

## 一镜一职能

`shot_function` 有三种取值，每一镜必须占其中一种：

- `change_emotion` —— 看完这一镜，观众的感受变了
- `advance_action` —— 看完这一镜，故事往前走了一步
- `raise_pressure` —— 看完这一镜，观众更担心/更期待了

**三者都不占的镜头，删掉。** 它只是在消耗时长。最常见的废镜头是
「展示一下环境」和「再来一个好看的角度」——如果环境信息可以在下一镜的
背景里交代，就不需要单独一镜。

## 三个物理事实

`three_facts` 是必填的三条，每条都必须**可拍**：

1. **环境压力** —— 这个空间正在对人施加什么：风、雨、人流、温度、
   光线变化、坡度、噪音。它让画面有动势，也让模型知道什么该动。
2. **身体微动作** —— 手指、呼吸、重心、视线、下颌、肩膀。
   大动作交代情节，微动作交代人。
3. **声音锚点** —— 这一镜能听见的**具体声源**。不是「氛围音」，
   是「板鞋踩在木板上的两声闷响」。

写不出三条，通常说明这一镜的内容想得还不够细。

**不可拍的写法**（这些都不算数）：

| 写了 | 问题 | 改成 |
|---|---|---|
| 她很紧张 | 拍不出情绪 | 她反复用拇指刮杯壁的水珠 |
| 氛围很温馨 | 拍不出氛围 | 灯泡是暖黄的，光只照到桌面一半 |
| 画面很有张力 | 什么都没说 | 两个人的影子在墙上快要碰到 |
| 微风拂面 | 太笼统 | 风把碎发吹到她嘴角 |

## 每镜只能有一个运镜

两个以上的运动会让生成结果失控——这是所有视频模型的共同点，
不是某一家的毛病。「一边推近一边右摇再升起来」的结果通常是画面
在原地抖，或者主体被甩出画框。

需要复合运动时，拆成两镜，用剪辑接。

`camera_motion` 的取值是**受控词表**，与视频模型的运镜指令一一对应：
写在表里的词会被翻译成模型认的指令，自由发挥的描述不会。

选景别的依据是**观众此刻需要看清什么**：

- 需要看清空间关系 → `wide` / `extreme_wide`
- 需要看清动作 → `medium` / `medium_wide`
- 需要看清表情 → `close` / `medium_close`
- 需要看清一个细节（手、物件、眼睛）→ `extreme_close`

角度是**态度**，不是变化。`low` 让主体显得有力，`high` 让主体显得孤立，
`dutch` 表示失衡——没有理由就用 `eye_level`，不要为了"有变化"而变角度。

## 连续性几何

视频模型**不知道上一镜的摄影机在哪**。跨镜头的空间连续性完全由你在
文字里保证：

- **轴线**：两个人对话时，摄影机始终待在他们连线的同一侧。
  越过去，观众会觉得两人突然换了位置。
- **视线方向**：这一镜她朝画面右侧看，下一镜被看的东西就该在画面左侧进。
- **运动方向**：向右跑出画面，下一镜就要从画面左侧进来。
- **30 度**：连续两镜拍同一主体，机位至少变化 30 度，否则看起来像跳帧。

这些在分镜里靠 `angle`、`subject`、`action_chain` 和转场说明表达，
写清楚它们比写一堆形容词有用得多。

## 转场

`transition_to_next` 要能被审计——后期是照着它拼的：

- **硬切**：默认。绝大多数短视频只需要硬切。
- **动作接**：上一镜动作未完，下一镜接着完成。写清接在哪个动作上。
- **声音先入（J-cut）**：下一镜的声音先进来。写清是哪个声音。
- **淡出**：只用在结尾。中间用淡出会把节奏打断。

没想清楚就写硬切。花哨的转场是新手最容易犯的错。
