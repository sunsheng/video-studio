# 调度先于构图

先决定人在空间里怎么动，再决定摄影机站在哪。反过来做，会得到一堆
好看但空的画面——因为构图是结果，调度才是原因。

## 起位 → 动作 → 落位

`action_chain` 写的就是这个：她从哪里开始，做了什么，停在哪里。

```
起位：靠在船舷右侧，背对镜头
动作：船头切开水面时转身
落位：面向镜头偏左 30 度，重心落在右脚
```

三段都要具体到**身体在空间里的位置**。「她转身笑了」缺了起位和落位，
模型只能自己编，编出来的每一镜都不一样。

## 一镜一个主动作

和运镜同理：一个镜头里塞两个完整动作，模型会把它们压缩成一个含糊的动作。

- 好：举起手机 → 摇向群岛 → 按下快门（这是**一个**连贯动作的三个阶段）
- 坏：她跑过来，然后坐下，然后拿出手机（这是三个动作，该拆成三镜）

判断标准：三段能不能一气呵成地做完？能就是一个动作。

## 摄影机的动机

镜头为什么要动？只有两个正当理由：

1. **跟随**——主体在动，镜头跟着看。
2. **揭示**——镜头动了之后，观众看见了原本看不见的东西。

两个都不占，就用 `static`。固定机位不是保守，是**默认**——
运动本身不产生意义，被运动揭示的东西才产生意义。

## 竖屏的空间

9:16 的画面横向只有一点点，调度要跟着变：

- **纵深代替横移。** 横向走两步就出画了，让人物朝镜头走近或走远。
- **前景是免费的纵深。** 让近处有东西（栏杆、树叶、杯子），
  画面立刻有层次，也让模型知道什么该虚化。
- **主体居中偏上。** 竖屏底部常被界面元素遮住，重要的东西不要放太低。
- **一次一个人。** 竖屏放不下两个并排的人还看得清脸。
  两人同框就用前后站位，或者一个在前景虚化。

## 三层空间

`foreground` / `midground` / `background` 三个字段是让你把空间**说满**：

- 前景给纵深和遮挡
- 中景放主体和主要动作
- 背景交代地点

三层都填了，画面才不是贴纸。只写中景，模型会给你一个悬空的人。
