# 前三秒

竖屏短视频里，观众决定要不要看下去的时间比一个镜头还短。
`hook_at_seconds` 写的是钩子在第几秒**成立**——不是第几秒开始，
是观众在第几秒已经get到了。这个数超过 3，基本等于没有钩子。

## 五种做法

**一、反差**
把两个不该同框的东西放进同一画面。西装革履的人蹲在路边吃面；
巨大的机器旁边站着很小的人。反差在**画面里**，不在文案里。

**二、悬置**
先给结果的一部分，不给原因。一只手把湿透的鞋放在暖气片上——
观众想知道发生了什么。注意：悬置不是藏着不说，是给一个**具体的**残缺信息。

**三、动作正中**
不从准备开始，从动作已经发生的那一刻开始。不要"她走向湖边"，
要"船头已经切开水面"。省掉起手式是短视频最有效的提速手段。

**四、直接的美**
风景、食物、光——当画面本身足够好，就让它自己说话。
但要**具体**：不是"美丽的湖景"，是"船头切开的水面把上午的光切成两半"。

**五、一句话立住的人**
一个动作立刻交代性格。她把碎发别到耳后时指尖停了半秒——
这个停顿比任何形容词都说明她是什么样的人。

## 反例

| 写法 | 问题 |
|---|---|
| 「以一个吸引人的画面开场」 | 没说是什么画面，等于没写 |
| 「唯美的湖景，氛围感拉满」 | 全是不可拍的形容词 |
| 「女主角出场，介绍她的身份和背景」 | 短视频没有介绍的时间，身份要靠动作透露 |
| 「用悬念抓住观众」 | 悬念是手法不是内容，具体悬的是什么？ |

## 钩子与第一镜的关系

钩子通常落在第一镜，但**不必等第一镜结束**。第一镜 1.4 秒，
钩子可以在 0.6 秒成立——剩下的 0.8 秒是让观众确认自己看到了什么。

如果第一镜要 2 秒以上才能让人明白发生了什么，先问：
是不是把起手式也拍进去了？
