# 方法手册

这里是**怎么想**，不是**交什么**。交什么由 `studio.schema` 说了算，
被什么挡住由 `blocked_by.remedy` 说了算——那些是契约，读一遍就够。
这里的东西不一样：它决定你产出的东西好不好看，值得在动手前翻开。

**不要一次全读。** 每份文档管一件事，按下表在需要的时候读那一份。

| 什么时候 | 读哪份 |
|---|---|
| 要定故事结构、分配时长 | `story/structure.md` |
| 要设计开头 | `story/hook.md` |
| 要写口播、字幕、任何被人读到的句子 | `story/voice.md` |
| 要把剧本变成镜头 | `camera/grammar.md` |
| 要定这一镜的光 | `camera/lighting.md` |
| 人物在空间里怎么走、机位放哪 | `camera/blocking.md` |
| 要让同一个人在五镜里还是同一个人 | `consistency/bible.md` |
| 要写声音、对白、音乐 | `audio/design.md` |
| 提交之前 | `quality/checklist.md` |
| 想知道哪些词不能写 | `quality/banned.md` |
| 生成结果不对劲 | `failure/modes.md` |
| 想看一份写好的长什么样 | `exemplars/` |
| 要写提示词 | `../models/` 里对应系列那一份 |

## 三条贯穿全部阶段的原则

**一、可拍的才算写了。**
「氛围感很好」「画面很美」「她很难过」都不是内容——模型拍不出「难过」，
只能拍「她把下巴埋进围巾，视线避开镜头」。凡是不能被摄影机记录的描述，
都等于没写。

**二、一个镜头是一个决定，不是一段形容。**
如果说不出观众看完这一镜多知道了什么，这一镜就不该存在。删掉它，
把时间给别的镜头。

**三、一致性靠复制，不靠复述。**
同一个角色的外观描述一次写定，之后**逐字复制**。每次重新组织语言，
模型就会给你一个新的人。
