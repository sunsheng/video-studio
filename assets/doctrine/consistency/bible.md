# 一致性

同一个人在五个镜头里是五个人——这是 AI 视频最容易露馅的地方，
也是观众最先注意到的问题。

## 身份锁

给每个跨镜头出现的角色写**一段外观描述，一次写定**，此后**逐字复制**
到每一处需要它的地方。不改写、不缩写、不"优化措辞"。

一段合格的身份锁包含：

```
年龄段 + 性别/族裔 + 发型发长发色 + 上装 + 下装 + 鞋 + 随身物 + 标志性特征
```

例子（可以照着这个密度写）：

> 20岁东亚女性，长黑发及胸，白色无袖连衣裙，低帮白色板鞋，奶油色小斜挎包

**为什么必须逐字**：模型对措辞极其敏感。「白色连衣裙」和「一条白裙子」
会生成不同的衣服；「长黑发及胸」和「乌黑的长发」会生成不同的发型。
每一次重新组织语言，都是在重新掷骰子。

**常见错误**：在分镜里写了身份锁，到提示词阶段觉得"重复太啰嗦"，
于是第二镜之后改成「同一位女孩」。模型不知道"同一位"是谁——
它没有记忆，每一镜都是从零开始。**每一镜都要带完整的身份锁。**

## 它在三个阶段之间怎么走

身份锁有一个字段位置，跨三个阶段传递：

| 阶段 | 字段 | 你做什么 |
|---|---|---|
| `storyboard` | `character_lock.identity_lock` | **写定**。这是唯一一次创作它 |
| `visual_assets` | `consistency_lock.character` | **复制**上一格的字符串 |
| `prompt_pack` | `identity_lock.character` | **复制**上一格的字符串 |
| `prompt_pack` | 每一镜的 `positive` | 让这个字符串**原样出现**在里面 |

这四格提交时都会自动比对：三处不是同一个字符串，报
`identity_lock_drift`；某一镜的 `positive` 里找不到它，报
`identity_lock_missing`。两条都挡提交。

挡的不是措辞，是**同一个人在第三镜变成另一个人**。复制粘贴，
不要凭记忆重打一遍——重打出来的十有八九差一个字。

## 除了人，还要锁什么

| 锁什么 | 内容 | 不锁的后果 |
|---|---|---|
| 角色外观 | 上面那段 | 换脸、换衣服 |
| 机位签名 | 这个角色主要用什么角度拍（例如"约30度侧脸"） | 每镜脸的朝向都不一样 |
| 环境 | 地点的固定特征：材质、颜色、标志物 | 同一个地方看起来像三个地方 |
| 光的方向 | 主光从哪边来 | 时间感错乱 |
| 时代与季节 | 年代、季节、天气 | 夏天的湖边出现羽绒服 |
| 排版禁止项 | 不要乱码文字、假字幕、水印 | 模型自己生成一堆假文字 |

这些写在分镜的 `character_lock` 里（外观那条写 `identity_lock`，
其余各占一个字段），提示词阶段照抄。

## 排版禁止项要写成正向约束

有的模型不吃负向提示词。「不要乱码字」这类要求要改写成正向句子：

> 画面中不出现乱码文字、假字幕或水印

比「无文字, 无水印, no text」这种词堆更可靠——**完整的句子比标签更容易
被理解**。具体到你用的系列吃不吃负向提示词，看模型能力卡。

**这一条挡的是模型幻觉出来的假字，不是标识本身。** 画面里要出现某个 logo、
图标、品牌，正常写进提示词就行，不受这条约束——见 failure/modes.md 的 F7。

## 文字之外的另一条腿

片段化的系列还能**把参考图直接喂给模型**：角色卡、场景卡写进这一镜的
`references`，模型看的是实物，比读文字描述准得多。

两条腿分工不同，**都要用**：

- **参考**解决「像不像同一个人」——模型有一张实物照片可以对齐；
- **身份锁的逐字复用**解决「模型有没有被告知要像谁」——参考只是素材，
  提示词里不点名要它像谁，模型不一定往那边靠。

所以有了参考也不要省身份锁。少任何一条，角色都会在第三镜变成另一个人。

走整图基线的系列没有这条腿（那些图没有图片输入槽位），一致性只能靠逐字
复用；具体到你用的系列有没有，看能力卡。参考怎么组、挂几张，见
`.agents/doctrine/assembly/shots.md`。
