# 一致性

同一个人在五个镜头里是五个人——这是 AI 视频最容易露馅的地方，
也是观众最先注意到的问题。

## 身份锁

给每个跨镜头出现的角色写**一段外观描述，一次写定**，此后**逐字复制**
到每一处需要它的地方。不改写、不缩写、不"优化措辞"。

一段合格的身份锁包含：

```
年龄段 + 性别/族裔 + 发型发长发色 + 上装 + 下装 + 鞋 + 随身物 + 标志性特征
```

例子（可以照着这个密度写）：

> 20岁东亚女性，长黑发及胸，白色无袖连衣裙，低帮白色板鞋，奶油色小斜挎包

**为什么必须逐字**：模型对措辞极其敏感。「白色连衣裙」和「一条白裙子」
会生成不同的衣服；「长黑发及胸」和「乌黑的长发」会生成不同的发型。
每一次重新组织语言，都是在重新掷骰子。

**常见错误**：在分镜里写了身份锁，到提示词阶段觉得"重复太啰嗦"，
于是第二镜之后改成「同一位女孩」。模型不知道"同一位"是谁——
它没有记忆，每一镜都是从零开始。**每一镜都要带完整的身份锁。**

## 除了人，还要锁什么

| 锁什么 | 内容 | 不锁的后果 |
|---|---|---|
| 角色外观 | 上面那段 | 换脸、换衣服 |
| 机位签名 | 这个角色主要用什么角度拍（例如"约30度侧脸"） | 每镜脸的朝向都不一样 |
| 环境 | 地点的固定特征：材质、颜色、标志物 | 同一个地方看起来像三个地方 |
| 光的方向 | 主光从哪边来 | 时间感错乱 |
| 时代与季节 | 年代、季节、天气 | 夏天的湖边出现羽绒服 |
| 排版禁止项 | 不要文字、logo、水印、字幕 | 模型自己生成一堆假文字 |

这些写在分镜的 `character_lock` 里，提示词阶段照抄。

## 排版禁止项要写成正向约束

有的模型不吃负向提示词。「不要文字」这类要求要改写成正向句子：

> 画面中不出现任何文字、标志或水印

比「无文字, 无水印, no text」这种词堆更可靠——**完整的句子比标签更容易
被理解**。具体到你用的系列吃不吃负向提示词，看模型能力卡。

## 现在还做不到的事

参考图（角色卡、场景卡）目前**没有通道进入渲染**：所有视频基线都还没有
绑定图片输入。也就是说：

- 一致性目前**只能**靠文字，也就是上面说的逐字复用；
- 提示词里的 `references` 字段可以照常写（它表达意图，也会被登记下来），
  但暂时不会出现在渲染请求里；
- 这不是你写错了，是管线还缺这一环。

在这个前提下，身份锁的逐字复用是唯一有效的手段，不要省。
