# 光与色

光分三个字段写，是因为它们是三件独立的事：光**从哪来**、光**怎么打**、
画面**偏什么色**。混在一句「柔和的暖光」里，模型只能猜。

## 光源：光从哪来

| `lighting_source` 取值 | 说明 |
|---|---|
| `daylight` | 自然日光 |
| `moonlight` | 月光：冷、暗、方向单一 |
| `practical` | 实用光：画面里能看见的灯，最容易出效果 |
| `firelight` | 火光：暖、跳动、方向低 |
| `fluorescent` | 荧光灯：偏绿、平、无情绪 |
| `overcast` | 阴天：大面积柔光，无明显方向 |
| `mixed` | 混合光：冷暖并存，需说明各自方向 |
| `artificial` | 人造光：影棚或不明来源的布光 |

光源决定画面的可信度。`practical`（画面里能看见的灯：台灯、霓虹、屏幕）
是最容易出效果的一种——因为观众能看见光源本身，画面立刻可信。

## 光型：光怎么打在主体上

| `lighting_key` 取值 | 说明 |
|---|---|
| `soft` | 柔光：阴影边缘柔和，皮肤平整 |
| `hard` | 硬光：阴影边缘锐利，反差大 |
| `top` | 顶光：眼窝落影，压迫感 |
| `side` | 侧光：一半亮一半暗，立体 |
| `back` | 逆光：主体压暗，边缘发光 |
| `rim` | 轮廓光：只有一道边光，把人从暗背景里分离 |
| `silhouette` | 剪影：主体全黑，只剩形状 |
| `bottom` | 底光：反常规照明，用于失常与恐怖 |

光型决定情绪，对照着挑：

| 光型 | 效果 | 适合 |
|---|---|---|
| `soft` | 阴影边缘柔和，皮肤平整 | 日常、轻松、人物友好 |
| `hard` | 阴影边缘锐利，反差大 | 正午、紧张、力量感 |
| `side` | 一半亮一半暗，立体 | 人物有心事、有分量 |
| `back` | 主体压暗，边缘发光 | 逆光剪影、告别、回望 |
| `rim` | 只有一道轮廓光 | 从暗背景里把人分离出来 |
| `top` | 眼窝落影 | 压迫、审问 |
| `bottom` | 反常规照明 | 恐怖、失常 |
| `silhouette` | 全黑剪影 | 强调形状而不是身份 |

## 色调

`color_tone` 是自由字段，但要写**可复现的说法**：

- 好：「上午冷白，低对比」「夕阳暖金，逆光」「青橙分离」「低饱和，接近单色」
- 坏：「高级感」「电影级调色」「氛围感很强」——这些词对模型没有任何作用

如果有具体的参照，直接写：「漂白旁路」「柯达 Portra 的肤色」
「霓虹青紫」都是模型能理解的说法。

## 一致性

**光的方向要跨镜连续。** 同一场戏里，主光不能这一镜从左边来、
下一镜从右边来——观众不一定说得出哪里不对，但会觉得不对。

时间在推进的片子（白天到黄昏）要在分镜里明确写出每一镜的时间点，
并让 `lighting_source` 和 `color_tone` 跟着变，否则模型会各拍各的。

## 和运镜的配合

一个常见的错误是给静止的画面配复杂运镜，指望"动起来"。
更有效的做法是**让光动**：云影扫过、车灯划过、灯泡摇晃。
光的变化比机位的变化更容易被模型稳定生成，也更不容易失控。
