# Wan 系列

`wan2_2`

## 这条系列吃什么

| 模式 | 可用 | 可注入参数 |
|---|---|---|
| `wan2_2/t2v` | 是 | `positive`、`negative`、`width`、`height`、`length_frames`、`fps`、`seed` |
| `wan2_2/i2v` | **否** | — |
| `wan2_2/flf2v` | **否** | — |

**写了会被静默丢弃**：`references`、`duration_seconds`。这些参数在这条系列上没有绑定——不报错、不留痕、也不生效。

标着「否」的模式尚未在真机上核验绑定，**不要选它们**——绑错节点会静默产出错的画面，比直接报错更难查。

## 提示词结构

这个系列吃**叙述式**的写法，不是标签堆。按镜头展开的顺序写：

```
开场画面 → 摄影机怎么动 → 揭示/落点
```

长度 80–120 词最稳。写太短，模型会用自己的默认审美填空，
结果时好时坏；写太长，重点会被稀释。

## 美学控制是分类词表

这个系列对分类明确的美学词响应很好。分镜里的字段直接对应：

- **光源**（`lighting_source`）：日光、月光、实用光、火光、荧光、阴天、混合光
- **光型**（`lighting_key`）：柔光、硬光、顶光、侧光、逆光、轮廓光、剪影、底光
- **景别**（`shot_size`）与**角度**（`angle`）：照分镜的枚举写
- **色调**（`color_tone`）：青橙、漂白旁路、柯达 Portra、低饱和
- **镜头感**：变形宽银幕虚化、16mm 颗粒

这些词写清楚，比堆十个形容词有用。

## 负向提示词在这条系列上是有效的

与 MiniMax 系列不同：`wan2_2/t2v` **绑定了 `negative`**，写了会真正生效。

负向提示词写**具体的失败形态**，不写抽象的好坏：

- 有用：`文字, 水印, 多余的手指, 肢体扭曲, 面部模糊, 画面撕裂`
- 没用：`低质量, 丑, 不好看`——模型不知道你觉得什么丑

注意：只有 `t2v` 是已核验的。`i2v` 和 `flf2v` 的绑定尚未核验，
当前只能注入种子，其余参数都不生效——在核验之前不要选它们。

## 时长

按帧数收时长：`length_frames` + `fps`。帧数不要超过 120。
默认 24 fps；16 fps 适合快速试稿。

## 与 MiniMax 系列的区别

| | MiniMax 系列 | 这条系列 |
|---|---|---|
| 运镜 | 方括号指令，放句首 | 写进叙述里 |
| 负向提示词 | 不支持，写了会被丢弃 | t2v 支持且有效 |
| 写法 | 结构化短句 | 叙述式，80–120 词 |
| 音频 | 音视频联合生成 | 不出音频 |

换系列就要换写法。同一份提示词直接搬过来，效果会打折。
